Portfolio website and home for other random projects.

The resume is available at https://tysonthompson.com/resume. To update it,
replace `Tyson_Thompson_Resume.pdf` and push to `main`; the existing deployment
workflow publishes it to cPanel. Apache's `.htaccess` serves the PDF at `/resume`
and `/resume/` without changing the public URL.

## Folio document workspace

[Folio](https://tysonthompson.com/googledocs/) is a shared document editor with
rich text, persistent autosave, text-file import, and demo-user sharing.
See [setup, review instructions, and architecture](googledocs/README.md).
